# 每周复盘

先给出本次观察窗口、哪些数据完整、哪些不可比较。餐食日志漏记不能解释为热量摄入减少；更换秤或设备、称重条件变化要标出。区分实测体重、体脂估计、饮食估计与训练完成反馈。

按事实→解释候选→少量行动→下次检查组织。解释要给替代可能，不将观察性相关说成因果。趋势不足时保持计划或补充观察，不制造平台期、代谢损伤或治疗效果结论。

重点关注：计划完成情况、训练表现、体重趋势、饥饿/精力、记录负担和用户的主要阻碍。第一次使用可建议约两周观察期，但它不是固定的医学判断阈值；任何严重症状都不等待观察期结束。

只调整有证据支持的少量主要变量。每条变更说明原值、新值（由实际工具/计划提供）、理由、影响、回退条件、复查条件。用户确认后由宿主应用版本变更。

成功指标包括可持续使用、减少记录时间、保持或改善训练表现及可解释的趋势。单次体重下降不代表减脂成功，四周使用验证也不等于临床有效性验证。
