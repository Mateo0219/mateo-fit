# Mateo Fit 0.8.3（16）：空白会话不进入历史

2026-11-04。用户要求点击新会话后，没有发送消息时不出现在左侧历史。

## 当前行为

- 新会话只打开输入界面。空白会话、仅有未发送文字或所选照片的会话不进入侧栏历史，也不进入历史搜索结果。
- 第一条消息提交到本地待发送队列后，会话立即进入历史；失败或停止的已发送消息仍可找回、重试。
- 未发送草稿继续保存在本机。切到已有对话后，再点“新会话”会恢复该草稿；反复点击复用同一个未开始会话，不累积空条目。
- 旧版本留下的空会话也按同一规则隐藏，没有删除原记录。旧版可能只有餐食分析结果、没有对话气泡的待确认会话继续可见，避免丢失确认入口。
- 模型菜单继续由服务端下发完整版本名称：DeepSeek V4.1 Flash (1017)、DeepSeek V4 Pro (0813)。本版未修改服务端和模型调用。
