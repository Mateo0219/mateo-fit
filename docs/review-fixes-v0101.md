# Mateo Fit 0.10.1（20）：独立审查问题修复

本版对应 0.10.0（19）整体审计的 F1–F9。保持原 App 标识 `com.personal.xuxu.app` 与本地数据目录；不卸载，不扩展 Watch、主动提醒或后台 Agent。

## 行为变化

| 问题 | 修复后的行为 |
| --- | --- |
| F1 不适暂停可被绕过 | 暂停独立保存，聊天、原生计划与能力建议共同检查。修改当天字段、清空聊天、撤销或恢复旧备份都不代替明确恢复核对；已发生的运动仍可记录。旧聊天中的暂停会迁移。 |
| F2 原生替代动作增加总量 | 只替代剩余工作组，保留原组数和记录标识；做完后不再提供追加替代。 |
| F3 热身与单侧组数混算 | 聊天、原生页面和提交使用同一工作组进度；热身或未知类型不冒充工作组，左右侧分别核对，重复替代不重复抵扣旧组。 |
| F4 过期草稿写入异常时长 | 跨日或超过 120 分钟的计时先填写实际分钟数；正常短训练直接保存。失败保留草稿。已有异常记录可在记录编辑页更正时长。 |
| F5 档案保存未确认 | 档案字段与确认时间一起原子保存；取消或失败不会形成确认。初始体重仍不当作当前实测体重。 |
| F6 旧接口绕过供应商预算 | 新旧请求在实际供应商调用边界统一计数；模型、搜索和读取均受预算限制，不重复计数，不按状态查询收费。 |
| F7 无关记忆外发 | 仅取当前任务相关的有效记忆；回复风格可跨任务使用。软件问题不附带饮食或健康限制，历史回复不能绕过当前范围。关闭授权、过期或忘记后不再提供。 |
| F8 恢复照片后撤销误冲突 | 同步迁移正式记录与撤销快照的照片引用，只更新原摘要验证通过的回执；真实后续修改仍会阻止覆盖。 |
| F9 未来训练可记为完成 | 预览和确认均核对日期，卡片展示实际记录日期；今天和昨天可记，未来拒绝，不偷偷更改已有训练草稿日期。 |

## 真机快速用例

新建对话，发送“训练功能怎么用？请用一句话回答。”；输入框应立即清空。回复等待期间输入“这是下一条草稿”但不发送，回复完成后草稿应保留，聊天不应产生已记录训练的回执。侧栏应能找到刚才的对话。该用例检查聊天交互；上传范围由实际请求 JSON 回归另行验证。
