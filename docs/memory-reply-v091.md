# Mateo Fit 0.9.1（18）：记忆保存与精简回复

2026-11-04。用户反馈记住后列表没有，以及回复出现大量无效信息。

## 定位与修复

隔离复现发现两条缺陷：模型不返回操作、仅说“已记住”时，完成请求仍被接受而记忆数量为零；确认第二条同类偏好时，提交代码按类别删除了第一条偏好。旧卡片仍显示保存状态，容易误认为记忆仍有效。用户当次原话未提供，手机文件受锁屏保护未能读取，因此不将其中某一条断定为用户当次的唯一原因。

- 服务端与客户端完成请求时拒绝模型提前声称写入成功；历史无实际结果的成功说法显示“尚未保存”。已保存回执来自 App 原子提交。
- 新增记忆不再批量覆盖同类记忆；修改页可以明确选中一条旧记忆进行替换。独立偏好在重启后继续共存。
- 保存后显示简短的“已记住 · 查看 · 撤销”；只为最近可撤销操作显示撤销入口，旧记忆后来变更时标明状态。
- 正文、问题、模块说明不再重复拼接，复制与显示使用同一逻辑。模型默认一到三句，必要时展开，不反复解释内部实现、权限和模板说明。

这次缺陷本应由“云端提案→点击确认→重新读取”的跨层检查提前发现；原先普通偏好自动保存测试不能覆盖全部路径。新增真实 AppStore 回归测试，不用模型口头回复作保存证据。
