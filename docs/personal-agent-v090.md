# Mateo Fit 0.9.0（17）：记忆与聊天内执行

2026-11-04。第一批个人 Agent 能力；目标生命周期、持续后台任务、主动提醒与自动复盘仍属后续范围。

## 使用

- 明确普通偏好可在本机直接记住，如“以后回答简短点”。保存后显示真实回执，可撤销；健康限制、冲突偏好和正式记录先核对。
- 侧栏“记忆”可查看来源、修订与有效期，修改或忘记。会话菜单可开启“不形成长期记忆”。清空聊天不会删除正式日志。
- 设置中的“在 AI 回复中使用记忆”默认关闭，开启后仅发送相关有效摘要。它与“结合我的健康记录”分别控制，选择持续有效；关闭会停止当前请求并排除相关历史回复。
- 聊天可提出实际训练组数、训练结束、餐食记录、更正、当天条件和器械替代。待确认卡提供修改、取消及一次确认；只有本地原子保存成功后才显示完成结果。
- “今天只有四十分钟”只更新明确字段，地点与精力不会用默认值冒充确认。替代只改变剩余组数，原组保留；更正使用原记录 ID。
- 撤销最近一次操作时重查受影响数据，防止覆盖后来修改。撤销快照只保存相关记录，避免复制整本日志拖慢保存；操作版本持续递增，撤销不使旧提案重新有效。

普通记录没有可靠营养数据时保持未知；没有精确器械档案的训练组不会自动用于该器械的能力递进。定量训练、替代与营养规则沿用既有确定性实现，没有新增临床处方。

## 协议与数据

`POST /assistant/respond` 同时接受旧协议与 `contract_version: 2`；`POST /agent/status` 返回 `assistant_contract_versions: [1, 2]`。第二版增加独立记忆摘要授权、会话记忆选项和结构化操作提案。

服务端和客户端分别检查 schema、证据引用、目标记录、字段范围及用户原话。模型没有写工具；最终由 App 检查当前快照、日期、计划条件及幂等状态，并保存操作回执。服务端不保存个人记忆库，供应商输入保留政策沿用既有披露。

本地 `AppData.personalAgent` 保存记忆、失效标记、操作与最近 20 次撤销回执。新字段可选，兼容旧 JSON 和备份。忘记或更正后停止取用旧对话回声；历史原文、正式日志、恢复前备份及用户导出的旧备份分别保留，忘记不代表清除所有副本。原始 HealthKit 样本仍留在手机。
