# GitHub 仓库内容说明

首次导入以当前工作目录的源码为准，不以旧发布 ZIP 替代当前文件。此前没有 Git 历史，因此首次提交是现状快照，不能用于推断旧版本的改动归属。

## 纳入版本控制

- Swift App、纯 Swift 核心、行为检查、Python 服务端及测试。
- 教练规则、响应契约、食品数据、第三方资源许可。
- Xcode 工程、构建脚本、无凭据的部署模板及工程说明。

## 仅保留本地

- 原始需求聊天摘录、含个人健康条件的训练说明。
- 本机开发状态、完整验收状态、设备与部署日志、截图、旧发布文件清单。
- 签名密钥、描述文件、环境凭据、运行数据库、健康记录和备份。
- 构建产物、缓存、Xcode 个人状态和重复工程副本。

以上由 `.gitignore` 排除，并未删除。本机原 README 的完整历史已保存在 `docs/local/README-before-github.md`。其他工程文档中的历史证据链接可能指向仅本机可用的文件；没有随仓库上传的原始证据，不能被视为已在当前克隆中复核。

首次导入保持业务源码与既有表单默认值不变；它不是去除所有个人化配置的公开发行版。初次推送采用私有仓库。以后若需要公开，应另行核对工程配置、历史文档和提交内容。
